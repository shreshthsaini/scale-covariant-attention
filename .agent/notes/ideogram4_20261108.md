# Ideogram 4 at 8192^2: working log (Ideogram owner, 2026-11-08)

HANDOVER Section 36 is the summary; this file holds decisions, numbers and the restart recipe.

## Decisions
- Native extent 4096^2 (n0 = 256), from the SEGA README's training-range assumption (lead: use it). 8192^2 = ratio 2.
- One pipeline for every method: the pinned SEGA copy (third_party/sega/ideogram4_sega). diffusers 0.39 ships
  Ideogram 4 too, but without SEGA's padding trim and maskless path (dense mask over > 65,536 tokens overflows 32-bit
  indexing; the SEGA README's horizontal-band bug at 4096^2) and with the full-length text RMSNorm.
- RoPE layout: the model rotates (j, j + 128) pairs; the SCA kernels rotate adjacent pairs. Permuting q / k channels
  (pair_perm) and repeating each frequency per pair (to_interleaved) makes them the same rotation; logits are
  invariant to a common channel permutation, values are not permuted. Tested to fp32 rounding.
- Coarse ids: h / w components 65536 + r // f; t stays 65536; text untouched. Brute-force test: global branch equals
  attention over a native Hc x Wc image built with the model's own MRoPE.
- Two reach tables (conditional and unconditional transformer have different weights; both see the full canvas).
- sca_v2 mapped by step fraction as the Qwen port: 14 of 48 global (FLUX.1: 8 of 28), then 2 steps each at 2, 1.75,
  1.5, 1.25 x n0 = 512, 448, 384, 320. At ratio 2 the scheduled windows are r = 1 to 1.6, below the only fitted scale
  (2); table_interp then reads the scale-2 table (its documented nearest-table rule). 512 covers the whole grid.
- 28 sigma bins for the reach tables (project default 14): the resolution-shifted logit-normal schedule keeps 17 of 48
  steps above sigma 0.93 at 4096^2 (one bin with 14 bins).
- Captions: Ideogram 4 is trained on structured JSON captions; the pipeline upsamples with Qwen3-VL + an LM head
  (temperature 1, seeded). Done once per prompt (aspect 1:1 serves 4096^2 and 8192^2), shared by all methods.
  outlines is not installed: unconstrained decoding, validated, redrawn with a recorded attempt seed if invalid.
- flex kernel options: sca/attn.py forces BLOCK_M 128 / BLOCK_N 64 / TMA (tuned at head_dim 128); at 256 those tiles
  may exceed shared memory. Ideogram contexts pass {} (torch's head-dim-256 defaults). The GPU check benchmarks options.
- MUSIQ: pyiqa 0.1.16 MUSIQ materializes full attention over all native patches (8192^2: ~65.7k tokens, ~100 GB of
  scores). Full-image MUSIQ is reported on a 4096 px downscale (musiq_4096); MUSIQ_c keeps the project's definition
  (four 1024^2 native crops, constancy_rope crop_boxes, seed 0).
- Prompts: showcase_page.json's 10 prompts in product / landscape / architecture / portrait (same prompts as the
  FLUX showcase on the page). Priority order in slurm/ideogram4_tasks.py ORDER; NTK / YaRN on the first 3.
- Lead's spool priority: 00a1_* (check, captions, fits, SCA), 00s1a1_* (SEGA, 4096^2), 00z_a1_* (full, NTK, YaRN).

## Cost estimate (FLOPs, before measurement)
Full attention 8192^2: 4 L^2 d per layer = 1.27e15 x 34 layers x 2 transformers x 48 steps = 4.1e18 attention
FLOPs (+ ~10% linear) -> 2 to 3 GPU-h per image at 400 to 600 TFLOP/s. SCA sca_v2: ~0.5 of full attention's attention
FLOPs (ratio 2 halves it; the scheduled windows cost up to 1.25 x full for 2 steps). check.json has the measured step
costs; the first SCA sidecar has the real per-image seconds and peak memory.
