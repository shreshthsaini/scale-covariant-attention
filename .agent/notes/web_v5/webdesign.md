## Contract with the other owners
- Components: `<figure class="comp-figure">` holds `.comp-fallback` (static) and `<div class="comp-mount" data-comp=NAME data-options=JSON>`; site.js loads c_NAME.css/js only when v5_assets.js lists them, mounts within 900 px of the viewport, adds .is-live on success. Mounted: heads (observation), emulate (method step 2), percentiles (see it), table (results).
- Videos: `<figure data-vrole=ROLE>` with `.vslot-media` fallback; roles used: hero16x9 / hero9x16 (hero, with the zoom readout from manifest.readout), speedrace, method_window, method_emulation, method_stages, explainer (section hidden until it exists). Process videos: site.js process() reads window.SCA_PROCESS (render_process_videos.py) else the single-pass traces filtered to prompts naming no person.
