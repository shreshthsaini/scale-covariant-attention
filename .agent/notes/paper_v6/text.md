## 4. Moved out of the main text (appendix owner: please make sure the appendix states these)
- The window start a(tau) = clip(t tau + floor(t/2) - floor(w/2), 0, H - w) per axis and the tile index
  tau = floor(p_i / t). The main text now says "the w x w block centred on its tile and clamped to the grid
  (Appendix D)". The proof of Proposition 2 defines a' itself, so nothing breaks there.
- The latent x_sigma = (1 - sigma) x_0 + sigma epsilon (sigma is now introduced as "noise level sigma" in Section 2).
- Reach emulation: "at every block and step both emulated views see the same queries, keys, and values" and "with r^2
  times fewer keys per view" (Limitations keeps "16 times fewer keys per view than the target").
- Intervals: "1000 or 2000 draws; set-level intervals also resample the 168 reference-image clusters" (now only
  Appendix D.3, app:intervals). v5.1 said "2000 draws" for all, which the appendix contradicts (original summaries
  use 1000); the main text now points to app:intervals instead of stating one number.
- Seeds "hash the prompt id and a seed label shared by all methods"; "campaign means on shared nodes are never ranked"
  (Table 1 marks campaign means with a double dagger and does not rank them); the timing rule is in app:timing.
- Protocol details: HRDiT's stages (decode, upsample, sharpen, re-encode, re-noise; guidance toward the low frequencies
  of the previous stage), AReA's sampler settings beyond "28 Euler steps at guidance 4.5" (shift mu = 1.15, bf16,
  tiled VAE decoding), the relative-error pooling ("over blocks, heads, and steps, on 32 prompts at 1024^2 and 16 at
  1280^2"), and the guidance values 3.5 / 4.5 / 6.0 of progressive SCA (now only Table tab:hparams).
