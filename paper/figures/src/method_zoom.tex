% SCA method, component-level zoom (appendix figure), TikZ, self-contained.
%
% Build from this directory:  tectonic --outdir .. method_zoom.tex   (writes ../method_zoom.pdf)
%
% Same visual language as method.tex: blue = global operator, amber = local,
% green = the calibrated mix, grey = text tokens and structure; titles 9 pt bold
% sans; labels 7 pt sans; single symbols and equations in CM math at 8.5 pt with
% 6.5 pt scripts.
%
% (a) Global operator and (b) Local operator are drawn on one toy grid over the
% Figure 1 cathedral (../teaser/square_bright.jpg, the brightened copy used by
% method.tex): H = 24 tokens per side, s = 4, n0 = H / s = 6, t = 2, w = n0 = 6.
% FLUX.1 at 4096^2 has H = 256, s = 4, n0 = 64, t = 8, w = 64.
%   (a) block-centre keys kappa(b) = s b + floor(s/2) = 2, 6, ..., 22 (blue dots);
%       one query (dark square, token (13, 9)) and its s x s block; the gathered
%       keys and the query on the coarse n0 x n0 grid of RoPE positions, with the
%       T text keys (grey) that every softmax also sees.
%   (b) query tiles of t x t tokens; the window of tile tau starts at
%       a(tau) = clip(t tau + floor(t/2) - floor(w/2), 0, H - w): an interior tile
%       (tile (3, 4), window cols 4..9, rows 6..11) and a corner tile (11, 11) whose
%       window is clipped from cols/rows 20..25 (dashed) to 18..23. The glyph is the
%       exact block mask of this toy in tile-major order (rows: 144 query tiles;
%       columns: text keys, then 144 key tiles), ../method_zoom/block_mask.png.
% (c) Gate and mix: pi_lh(sigma) of block 29, head 18 (one-based) from the
%     scale-4 table, linear between the 13 occupied bin centres (dots) as in
%     sca/attn.py PiTable; sigma > sigma_g = 0.89 is global only (veiled; the
%     effective weight is 0); ticks on the sigma axis are the 28 sampling steps.
% (d) The whole scale-4 table s4_pi_head of src/data/k1_1024_pi.npz: 1368 head
%     columns (57 blocks x 24 heads; heads sorted within each block by their mean
%     applied pi) by 14 noise bins (sigma 1 at the top to 0 at the bottom; bin 0 is
%     unpopulated and repeats bin 1), raster ../method_zoom/pi_strip.png in the
%     paper-wide pi colormap (scafig.PI_CMAP), with the gate band sigma > sigma_g
%     veiled. The two rasters and the data macros below were written from the .npz
%     by a helper script; ../method_zoom_provenance.json records the full recipe
%     (key, head order, bins, colormap, upsampling, hashes).
