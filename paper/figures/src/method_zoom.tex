% Appendix method zoom (Figure D.1, fig:method_zoom): the operators of Figure 3 at component level, operator sca_v2.
% TikZ, self-contained apart from ../method_zoom/{data.tex, pi_strip.png, block_mask.png}, which fig_method_zoom.py
% writes (its docstring and ../method_zoom_provenance.json record every source and rule).
%
% Build from this directory:  ~/.local/bin/tectonic --outdir .. method_zoom.tex   (writes ../method_zoom.pdf)
% Drawn at print size (1 unit = 1 pt, canvas 5.5 in x 250 pt), placed at \linewidth, in the visual language of
% Figure 3: titles 8.5 pt bold sans, labels 7.5 pt, numbers 7 pt, math 8 pt (scripts 6 pt); blue = global,
% amber = local (dark amber: bridge), green = SCA's weight and output, grey = neutral.
%   (a) Global operator on a toy grid (H = 24, s = 4, n0 = 6): the centre token kappa(b) of each s x s block (blue)
%       becomes a key at coarse position b; query i (black) moves to c(p_i).
%   (b) Local operator on the same grid (t = 2): two query tiles, their windows at w = n0 (filled) and w = 2 n0
%       (dotted), the border clamp (dashed: the unclipped start a'), the bridge (dark amber; schematic, one token
%       per cell of a 4 x 4 partition), and the block mask at w = n0 (grey text keys, dark amber bridge, amber
%       window tiles).
%   (c) Gate and mix: pi of the head of Figure 3 against sigma (rising left to right, as in Figures 5 and B.1)
%       at r = 2 (dashed) and r = 4 (solid); amber dots: the four window steps, read between the tables at
%       r = 256 / w; green dots: the 16 native steps at r = 4; grey: sigma > sigma_g, global only.
%   (d) The r = 4 table: 57 blocks x 24 heads (sorted per block) x 14 noise bins, sigma rising upward.
