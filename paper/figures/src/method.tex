% SCA method diagram (Figure 2), TikZ, self-contained.
%
% Build from this directory:  tectonic --outdir .. method.tex   (writes ../method.pdf)
%
% Layout follows REFERENCE_STYLE.md: two panels, at most 12 labels of at most
% three words each, no equations, single symbols only (sigma, pi, s). Blue is
% the global operator, amber the local one, grey everything else.
%
% Left panel, "Apply at target": a 28-step denoising strip, sigma 1 -> 0.
% The first 8 steps (sigma > sigma_g = 0.89, FLUX.1 shifted schedule, mu = 1.15)
% are global-only and drawn solid blue; afterwards each step cell is split into
% an amber (local) share pi and a blue (global) share 1 - pi, with pi the mean
% of the archived scale-4 table (src/data/k1_1024_pi.npz, s4_pi_head, all 57
% blocks and 24 heads) interpolated at that step's sigma. Below it, a 32 x 32
% token grid drawn over a real SCA output (../teaser/square.jpg, the cathedral
% of Figure 1, downsized by \includegraphics) at one scale, s = 4, n0 = 8,
% t = 2: the t x t query tile, its native n0 x n0 sliding window (start a(tau)
% of Section 2.2) and the n0 x n0 block-centre keys kappa(b) = s b + floor(s/2).
% FLUX.1 itself has n0 = 64 and t = 8.
%
% Right panel, "Calibrate at 1024^2": a native-size run (thumbnail is the SCA
% output ../qual_main/cmp_m2729538226706404616_sca_nb.jpg, a stand-in for the
% calibration prompts), the three operators as glyphs (full, global, local),
% and the fitted table of block 29 (zero-based 28) of the same scale-4 table:
% 24 heads (rows, original order) by 14 noise bins (columns, sigma decreasing
% left to right), coloured with the paper-wide pi colormap of scafig.py. The
% data macros at the end were written from the .npz with that colormap.
