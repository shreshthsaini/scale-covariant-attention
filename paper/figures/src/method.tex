% SCA method diagram, operator sca_v2 (main.tex Figure 2, fig:method), TikZ, self-contained.
%
% Build from this directory:  ~/.local/bin/tectonic --outdir .. method.tex   (writes ../method.pdf)
% Assets and data macros live in ../method_flow/ and are written by fig_method_flow.py (its docstring and
% ../method_provenance.json record every source and rule). Built at full text width (5.5 in) and placed at
% \linewidth, so sizes here are printed sizes: titles 8 pt bold sans, labels 7 pt, ticks 6.5 pt, math 8 pt
% with 6.5 pt scripts (Helvetica metrics, Computer Modern math).
%
% Colours (sca_colors.tex): blue = global branch, amber = local branch, green = SCA's weight pi, grey =
% neutral. The pi colormap runs from blue (pi = 0, global) through a light neutral to amber (pi = 1, local).
%
% (a) Apply at target, 4096^2 (256 x 256 tokens). Strip: the 28 steps; steps 1-8 (sigma > sigma_g = 0.89)
%     are global only; later steps split into the mean local weight (amber, top) and global (blue). The four
%     shrink steps 9-12 (outlined green) read pi_h at ratio r = 256 / w between the r = 2 and r = 4 tables.
%     Thumbnails under each phase: opening, the block-centre view (64 x 64 cells; blue dots schematic, one
%     per 16 x 16 tokens); shrink, the windows of side 128, 112, 96, 80 around the query tile (black), to
%     scale; native, the n0 = 64 window. Amber dots: schematic bridge tokens (real: 16 in every cell of an
%     8 x 8 grid, 1,024 tokens, recomputed per block and step).
% (b) Calibrate at 1024^2: emulated ratios r = 2 and r = 4 on the native grid (16 x 16 schematic: window
%     n / r, block-centre stride r, query black) fit the tables of block 8 (24 heads x 14 noise bins, sigma
%     1 -> 0 left to right); sigma > sigma_g is veiled, and the green band is the sigma range of the shrink
%     steps.
